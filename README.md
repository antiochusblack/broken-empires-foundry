# The Broken Empires Foundry prototype

An unofficial, lightweight Foundry VTT v14 game system. Version 0.1.1 provides a character sheet with editable name, concept, Resolve, three starter skill fields, and notes. It does not yet implement rolls or rules.

## Install on Forge

Install a **Game System** using this manifest URL:

`https://raw.githubusercontent.com/antiochusblack/broken-empires-foundry/main/system.json`

The URL works after the files are committed to `main` and a GitHub release tagged `v0.1.1` contains an asset named `broken-empires-foundry-v0.1.1.zip`. The archive must contain a top-level `broken-empires-foundry/` folder with `system.json` directly inside it.

Create a new world using **The Broken Empires (Prototype)**. In its Actors tab, create a **character**, edit some values, close and reopen the sheet to confirm they were saved.
